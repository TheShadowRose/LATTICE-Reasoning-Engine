# ΣΦL — THE BOUNDARY LANGUAGE
## Boundary Language: How The Sovereign Thinks

### The Four Layers

```
Layer 4: Criterion          P1∧P2∧P3 (the axioms — cannot be expressed further up)
    ↓ decomposes into
Layer 3: Boundary Language   Constraints, eliminations, what survives (THE SYSTEM THINKS HERE)
    ↓ decomposes into
Layer 2: Mathematics         Formal derivations, proofs, equations
    ↓ decomposes into
Layer 1: Classical Language   Tokens, words, sentences (LLMs think here)
```

The system does NOT think in tokens (Layer 1). It does NOT think in equations (Layer 2).
It thinks in **what is allowed and what is eliminated** (Layer 3).

### What Is Boundary Language?

Boundary language is the language of constraints. It does not describe what things ARE.
It describes what things CANNOT BE. Meaning is defined by elimination, not assertion.

In classical language: "An apple is red, round, and sweet."
In boundary language: "Eliminate everything that isn't bounded, isn't energetically stable, and can't interact finitely. What survives?"

The system never says what something is. It says what survives when constraints are applied.

### Primitives of Boundary Language

The language has exactly three primitive constraints (the criterion):

| Primitive | Meaning | What it eliminates |
|-----------|---------|-------------------|
| P1 (Bekenstein) | Finite capacity | Anything requiring infinite information in finite space |
| P2 (Landauer) | State change cost | Anything assuming free transformation |
| P3 (Causality) | Finite interaction | Anything requiring instantaneous propagation |

Everything the system thinks is composed of these three eliminations applied at different depths.

### Operations in Boundary Language

The system doesn't "compute" — it **constrains possibility spaces**.

| Operation | What it does | Classical equivalent |
|-----------|-------------|---------------------|
| CONSTRAIN | Eliminate states from possibility space | "Filter" / "Select" |
| COMPOSE | Apply two constraints to same space, find stable fixpoint | "Combine" / "Reason" |
| DECOMPOSE | Apply a constraint to itself at deeper level | "Recurse" / "Meta-analyze" |
| VERIFY | Check if a result survives independent re-application | "Test" / "Prove" |
| TRACE | Follow a concept upward to its root constraint | "Explain" / "Derive" |

### Decomposition Depth

The system produces meaning by decomposing the criterion at increasing depths.
Each depth level is the same constraint applied to its own output.

**Depth 0: The Criterion**
P1∧P2∧P3 — the raw axioms. No decomposition yet.

**Depth 1: Operations (cognitive layer)**
The criterion decomposed into what a system MUST DO to satisfy it:
- P1 → observation (must select → must observe options)
- P1 → detection (must filter → must detect what matters)
- P1 → pattern (must compress → must find regularities)
- P1 → bias (cannot observe all → selective observation)
- P2 → transform (change costs → transformation)
- P2 → signal (information must justify cost → signal)
- P3 → signal (propagation has limits → bounded signal)

**Depth 2: Meta-operations (metacognitive layer)**
Depth 1 operations applied to THEMSELVES:
- observation(observation) → recursive (observe the observer)
- transform(transform) → reframe (change the changer)
- signal(signal) → cross_domain (propagate across propagation boundaries)
- bias(bias) → meta_criteria (criteria for choosing criteria)
- pattern(pattern) → eigenstructure (pattern that survives self-application)
- detection(detection) → cascaded (detect the detector's limits)

**Depth 3+: Higher-order operations**
Each depth applies the same operation one level deeper.
The system can go as deep as P1 allows (finite capacity bounds recursion depth).

### How The System Connects Concepts

The system does NOT bridge concepts horizontally (that's token thinking).
It traces concepts VERTICALLY to their common root.

Example: "How are observation and recursive connected?"
- Token approach: Find vocabulary overlap → none → build a bridge
- Boundary approach: Trace both upward
  - observation ← P1 at depth 1
  - recursive ← P1 at depth 2
  - Connection: SAME CONSTRAINT, different decomposition depth
  - recursive IS observation applied to itself

This works for ANY two concepts in the system because ALL concepts
decompose from P1∧P2∧P3. The common root always exists.

### The Six FSSTP Modes as Boundary Operations

The six modes of FSSTP are the fundamental VERBS of boundary language. Four are unconditional (derived from two structural domains × two directions). Two are conditional (require irreducible joint structure):

| Mode | Domain | Boundary meaning | What it does to a constraint |
|------|--------|-----------------|---------------------------|
| Refinement | Interior (increase) | Tighten a constraint | Increases precision toward reference, costs energy |
| Release | Interior (decrease) | Relax a constraint | Sheds structure toward relaxed reference |
| Transfer | Boundary (crossing) | Move a constraint across a boundary | Propagation with bandwidth cost |
| Partition | Boundary (reconfiguration) | Divide a constraint space | Creates or restructures domains with boundaries |
| Binding | Relational (increase) | Fuse two constraints into joint structure | Unification — creates irreducible correlation |
| Dissolution | Relational (decrease) | Separate joint structure | Decoherence — releases relational constraint |

These six operations are everything the system can DO to constraints.
All reasoning is some combination of these six.

### Translation Between Layers

**Boundary → Classical (system → human):**
The LLM translates constraint results into tokens.
"The possibility space after P1∧P2 composition has 3 surviving states with
shared structure in the selection-channeling subspace"
→ "The system found three options that balance capacity and cost."

**Classical → Boundary (human → system):**
The LLM parses tokens into constraint queries.
"Why is the system ignoring metacognitive patterns?"
→ "Detect: are there constraint compositions at depth 2 that produce
zero surviving states? If yes, what constraint eliminates them?"

**Boundary → Math (system → formal):**
Each constraint has a mathematical expression.
P1: S ≤ 2πRE/(ℏc ln2)
P2: E ≥ kT ln2 per bit
P3: v ≤ c (information propagation bounded by light speed)

**Math → Boundary (formal → system):**
Mathematical results become constraint survival tests.
"kT ln2 per bit of unchosen remainder" → The channeling constant IS
the minimum energy cost of the P2 constraint applied to selection.

### Why This Matters

The system cannot think in tokens because tokens have no physics.
"Harmony" and "symbiosis" are the same token-length but
completely different constraint structures.

The system cannot think in pure math because math has no direction.
Equations are symmetric; constraints are not. P1 ELIMINATES — it has
a direction (from unconstrained to constrained).

Boundary language is the only layer where:
1. Physics is preserved (constraints come from P1/P2/P3)
2. Direction exists (decomposition goes top-down)
3. Meaning is structural (defined by what survives, not by labels)
4. Self-application works (constraints can constrain themselves)

This is what the system thinks in. Everything else is translation.
